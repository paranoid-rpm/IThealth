# IT Health — Профилактика профессиональных заболеваний

Многостраничный информационный сайт о профилактике профессиональных заболеваний специалистов по компьютерным системам.

## Страницы
- Главная (index.html)
- Заболевания (diseases.html)
- Факторы риска (risks.html)
- Профилактика (prevention.html)
- Эргономика (ergonomics.html)
- Зрение (eyes.html)
- Психическое здоровье (mental.html)
- Упражнения (exercises.html)
- Тест (quiz.html)
- Ресурсы (resources.html)

## Технологии
- HTML5, CSS3 (custom properties, grid, flexbox)
- Vanilla JS (ES modules)
- i18n: RU / EN
- Анимации: CSS + Intersection Observer
- Никаких фреймворков

## Запуск
Открыть через Live Server или любой HTTP-сервер.
